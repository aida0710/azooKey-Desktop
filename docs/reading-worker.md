# 候補処理から独立した読みプロセス

`AZOOKEY_BRIDGE_ROLE=reading` は開発検証用の明示的な入口です。通常の IBus frontend はこの値を設定せず、既存の bridge を使用します。ライブ変換や候補選択を備えた経路の置き換えは、まだ行っていません。

この入口は `BridgeMain` が converter、学習ディレクトリ、辞書を初期化する前に分岐します。別プロセスの `DesktopReadingWorker` が context ごとに `DesktopReadingSession` を持ち、Core の `UserAction`、`InputState`、`CompositionState` で入力を解釈します。ローマ字変換を Python へ複製しません。

現在の protocol は `key`、`reset`、`snapshot`、`close` です。読みは標準ローマ字・ライブ変換 OFF を前提にしています。文字入力、前後削除、読み内カーソル移動、Escape、読みの Enter / keypad Enter 確定を、候補の返信なしで完了できます。カーソルは既存の IBus protocol と同じ Unicode scalar 単位です。

未接続の予測・数字による候補確定・F6〜F10等は `unsupported_reading_action`、再変換 shortcut は `reconversion_requires_coordinator` を返します。操作が途中で失敗しても、正式な読み、カーソル、状態、世代を変更しません。未知の operation は `invalid_request` です。呼出側はこれらを成功した入力返信として適用してはいけません。

候補の採用と選択は `DesktopReadingSession` の内部 API に実装しています。`prepareCandidates` が正式入力を保存し、`adoptCandidates` が要求・読みプロセス・focus・設定の各世代、文脈、正式入力と消費範囲を照合します。採用だけでは未確定文字・カーソル・表示世代を変更しません。pointer / AT / 遅れて届く操作は一覧の参照と候補 ID を指定し、番号だけで新しい一覧を選ぶことを防ぎます。

Space・下矢印は必要な読み区切りを正式入力へ加え、候補がなければ入力応答に `request: "candidates"` を返します。その間は読みを表示し続け、候補到着後の明示キーで選択します。この開発段階では、到着だけで変換表示へ進めません。候補待ちのEnterは読みを確定し、Escapeは変換要求を取り消して読みを残します。さらにEscapeを押すと読みを取り消します。

Shift＋左右は実際に選んだ候補の消費範囲を基準に文節を変更し、変更後の正式入力を要求に使用します。候補待ちでSpaceを押しても編集した範囲は保持します。選択中のSpace・Shift＋Space・上下矢印は現在の一覧内を移動し、Enterは選択した候補IDを確定します。全読みを消費する候補を優先してpreviewし、なければ実在する先頭候補を使います。複数候補の単語を組み合わせません。

明示選択後の Enter は、その候補と検証済みの残る読みを使用します。候補プロセスが停止しても、表示済みの選択対象を変えません。学習通知は元の入力応答にだけ含め、通常の snapshot や次のキーへ再送しません。Enterや右矢印による部分確定後は文脈も更新して残りの候補を要求し、到着待ちでもEnterで残る読みを確定できます。選択取消・編集では古い選択を外し、選択中の英数切替では表示中の文字を確定します。選択した接頭辞と生の読みを一括確定する場合、その組合せを架空の候補として学習させません。

これらの候補 API の JSONL 接続、設定同期、候補プロセスの retain / release / 学習通知、frontend の制御は未接続です。ライブ変換 ON もこの入口に接続していません。未接続の操作を本番入力で無視するための入口ではありません。

回帰では実際の候補 bridge を起動して `SIGSTOP` の完了を確認し、その間に別の読み bridge で入力・途中編集・Enter・次の入力・Escapeを実行します。候補側の停止状態を再確認してから復帰し、両方の子プロセスを終了します。読み側のデータ先をディレクトリを作れない通常ファイルにして、学習ディレクトリを必要としないことも確認します。

この試験はプロセス分離と読みの保持を確かめるものです。実アプリの key-to-paint 時間や、候補との統合後の IBus / GTK / Qt / Wayland 動作の合格には代えません。
