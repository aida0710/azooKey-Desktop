# 履歴学習の設定

macOS と Ubuntu で同じ意味の選択肢を表示します。設定を切り替えるだけでは、保存済みの学習データを削除しません。

| 表示 | 新しい学習を保存 | 保存済みの学習を変換に利用 |
| --- | --- | --- |
| 学習して利用する | する | する |
| 新しい学習を停止し、これまでの学習を利用する | しない | する |
| 学習データを利用しない | しない | しない |

「履歴学習データを削除」は、確認後に履歴学習だけを削除します。ユーザー辞書、取り込んだ辞書、個人化モデル、設定は残ります。削除は取り消せません。

macOS の「取り込んだ辞書を削除」は、azooKey に取り込んだシステム辞書のコピーだけが対象です。macOS の辞書原本は残り、再度取り込めます。履歴学習の削除とは別の操作です。

## 回帰確認

`Linux/tests/test_bridge.py` の学習モード試験は、隔離した保存先に実際の変換候補「京」を学習させます。新規プロセスで「新しい学習を停止」を選ぶと順位へ反映され、「学習データを利用しない」では元の順位へ戻ることを確認します。両モードで別の語を確定しても、保存済み学習ファイルは書き換えず、削除しません。ニューラルモデルによる順位変動は、この学習方針の比較から分離しています。

macOS の確認ダイアログと VoiceOver、Ubuntu の設定画面と Orca の実際の読み上げは、GUI の確認項目です。ソースや自動試験だけでは完了と扱いません。
