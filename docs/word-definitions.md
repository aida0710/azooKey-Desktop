# 変換する前に単語の意味を確認する

開発版のazooKey Treeでは、木を表示する変換メニューに、候補一覧で選んだ語の右隣に意味を表示します。通常の変換操作を知っている方向けの案内です。最初の節で操作を確認し、辞典の違いや開発手順は必要なときに参照してください。

## 候補を選ぶと短い説明を表示する

ライブ入力中は従来の枝を含む木を表示します。Spaceなどで変換メニューを開くと、選択中の語の説明を検索します。全文候補を選んだ場合も、その候補の経路にある現在の文節を対象にします。候補の選択・確定キーは変わりません。

候補一覧は番号と単語を中心に、行の余白を抑えて表示します。初期表示は7件で、設定の「候補の表示件数」から5・7・9件を選べます。収まらない候補は一覧内でスクロールでき、数字キー1〜9とページ移動の単位はそのままです。確定・前後移動は、一覧の下に枠のない小さな操作として表示します。

意味が見つかった候補には、行の右端に小さな本のアイコンが付きます。意味のない候補には何も付きません。単語の意味は右隣の独立したカードに表示し、候補を選び直すと説明も切り替わります。意味が見つからない場合は、説明カードもその分の余白も表示しません。長い説明は「詳しく」で開き、説明カードの中をスクロールして読めます。説明の開閉で候補一覧は広がりません。部分確定で読みが残る場合や文節を調整する場合は、その情報も表示します。

候補から説明へマウスを移したときは、その語の説明を保ちます。画面右端ではカードを左へ寄せ、極端に狭い画面では横スクロールで説明へ移動できます。文字サイズは縮めません。Ubuntuでは辞典に用例や類語がある場合だけ、それらも詳細へ表示します。類語は語義ごとに最大8語の参照表示で、変換候補には追加しません。

木を非表示にしたリスト画面や、Ubuntuの標準IBus候補画面には、この機能はまだありません。語の境界を取得できない全文候補について、Ubuntuは単語を推測して検索しません。macOSは表示されている全文を検索対象にします。

## 辞典と読みの扱いはOSによって異なる

| 環境 | 使用する辞典 | 表示できる内容 |
| --- | --- | --- |
| UbuntuのGTK候補画面・GNOME拡張 | 同梱の日本語ワードネット1.1 | 収録されている語釈・用例・類語 |
| macOSの木の候補画面 | macOSのDictionary Services | OSの辞典から得られる説明文。用例や辞典名を独自に補いません。 |

Ubuntuの検索処理は同梱データを読み、入力中の語を外部サービスへ送りません。出典リンクをクリックした場合は、辞典の公式ページをブラウザで開きます。検索した語をURLに含めることはありません。

同じ表記に複数の読みがある場合、別の読みの語義が含まれることがあります。日本語ワードネットに読みが無い項目は、表記が一致する語義をまとめて表示します。macOSも表記で検索します。未収録の場合は説明を見つけられなかった旨を表示し、AIで説明を生成しません。

ATOKの辞典や学習履歴は使用していません。日本語ワードネットは語の意味関係をまとめたデータで、国語辞典・専門辞典の網羅性や最新性を保証するものではありません。

## Ubuntu用の辞典を開発環境に用意する

配布物を作る開発者は、先に以下を実行してください。Pythonの標準ライブラリだけを使い、OSのパッケージを追加する必要はありません。

```sh
python3 Tools/fetch-wordnet.py
python3 Tools/fetch-wordnet.py --verify-only
```

取得する版・サイズ・SHA-256は `Tools/wordnet-manifest.json` に固定しています。圧縮データは約60MB、展開後は約203MBです。`build/wordnet/` にデータ、出典情報、原文のライセンス2件を用意します。データをGitには追加しません。

検証済みの圧縮データが手元にある場合は、ネット接続なしでも準備できます。

```sh
python3 Tools/fetch-wordnet.py --archive /path/to/wnjpn.db.gz
```

`Tools/build-linux.sh` は配置前にデータ・ライセンス2件・出典情報の4ファイルを検証し、不足・改変があれば終了します。Docker経由の配布物作成も同じ検証を行います。辞典は `/opt/azookey-tree/dictionaries/` に同梱されます。

## 出典と検証の範囲

[日本語ワードネット1.1](https://bond-lab.github.io/wnja/index.ja.html)を使用しています。ライセンス原文は `packaging/licenses/japanese-wordnet.txt` と `packaging/licenses/princeton-wordnet-3.0.txt` に保持し、Ubuntuの配布物にも同梱します。詳細画面に日本語ワードネットの著作権表示と出典を示します。

macOSの実入力・実辞典・App Sandbox・VoiceOverはApple実機での確認が必要です。R540にmacOS VMは作成しません。自動試験の成功だけで、実機の確認済みとは扱いません。

機能の相談や不具合は [Issue #88](https://github.com/aida0710/azooKey-Desktop/issues/88) へお知らせください。ここで「語釈」は語の意味の説明、「用例」は辞典に収録された使用例を指します。
